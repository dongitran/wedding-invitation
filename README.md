> Elegant wedding invitation website with premium animations

## 🌸 Features

- ✨ GSAP animations with smooth scroll
- 📱 Fully responsive design
- 🎨 Champagne & sage color palette
- 💌 RSVP functionality
- 🖼️ Photo gallery
- 📍 Location details

## 🛠️ Tech Stack

- HTML5
- Tailwind CSS
- GSAP (animations)
- Lenis (smooth scroll)
